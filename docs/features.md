# Extra features & integrations

rfm works fully on its own, but it plays nicely with a few external tools and
with your shell when they're available. Everything on this page is optional.

## Previews

rfm shows text-file and image previews out of the box, with no extra
dependencies. For a few more file types it can use optional external programs if
they are present — otherwise it falls back to its built-in engine (or shows
nothing).

| Feature | Needs | Install |
| --- | --- | --- |
| Audio / video metadata | `mediainfo` | `apt install mediainfo` · `pacman -S mediainfo` · `nix-env -iA nixpkgs.mediainfo` |
| Syntax-highlighted text | `bat` | `apt install bat` · `pacman -S bat` · `nix-env -iA nixpkgs.bat` |
| `.tar` / `.tar.gz` listings | `tar` | `apt install tar` · `pacman -S tar` · `nix-env -iA nixpkgs.gnutar` |
| `.zip` listings | `zip` | `apt install zip` · `pacman -S zip` · `nix-env -iA nixpkgs.zip` |

Notes:

- `mediainfo` is also used as the preview engine for some `application/*`
  mime-types.
- If `bat` is not installed, text previews are generated by rfm's internal
  engine (without syntax highlighting).

## Zoxide

If you have [zoxide](https://github.com/ajeetdsouza/zoxide) installed, rfm can use
it as a smart `cd`: type `CD` (shift-cd, configurable) to open a zoxide-backed
jump mode and cycle through the results with `Tab` / `shift+Tab`.

rfm also **feeds** zoxide: every directory you visit in rfm is added to the
zoxide database, so your jumps keep getting better over time — in rfm and in your
shell alike.

```shell
# install zoxide
apt install zoxide · pacman -S zoxide · nix-env -iA nixpkgs.zoxide
```

The keybinding is configured under `[manipulation]` in `keys.toml` (see
[configuration.md](configuration.md)):

```toml
[manipulation]
zoxide_query = [ "CD", "Cd", "cD" ]   # "shift+cd" with typos allowed
```

## cd into rfm's last directory on exit

By default rfm leaves your shell where it started. If you'd like your shell to
`cd` into the directory rfm was in when you quit, wrap it in a small function.

Add this to your `.bashrc` / `.zshrc` (or the equivalent for your shell):

```shell
function rfm-cd {
    # create a temp file and store the name
    tempfile="$(mktemp -t tmp.XXXXXX)"

    # run rfm and ask it to write its final path into the temp file
    rfm --choosedir="$tempfile"

    # if the temp file exists and its path differs from the current one, cd there
    test -f "$tempfile" &&
    if [ "$(cat -- "$tempfile")" != "$(echo -n `pwd`)" ]; then
        cd -- "$(cat "$tempfile")"
    fi

    rm -f -- "$tempfile"
}

alias rfm=rfm-cd
```

This works exactly like ranger's `ranger-cd`, so if you already have that set up
you can just swap `ranger` for `rfm`.
